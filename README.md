NES emulator for the browser built on [jsnes](https://github.com/bfirsh/jsnes),
with a custom WebGL CRT pipeline, P2P netplay, and time rewind. Named after
the TV channel you tuned to for the real thing.

## Features

- **Headless jsnes core** — the emulator runs detached from any UI; video goes
  straight from the framebuffer to a WebGL texture, audio to an AudioWorklet.
- **CRT shader** (WebGL) — barrel curvature, scanlines, aperture-grille mask,
  phosphor glow, chromatic aberration and vignette, all tweakable live from
  the side panel. Overscan (8px top/bottom) is cropped like a real TV.
- **P2P netplay** — WebRTC via peerjs using deterministic frame lockstep:
  peers exchange only controller bytes (2 per frame), with a 3-frame input
  delay to hide latency. The host ships the ROM to the guest automatically.
  Host is player 1, guest is player 2.
- **Rewind** — hold <kbd>Backspace</kbd> to travel back up to ~60 seconds,
  powered by jsnes state snapshots taken 4×/s.
- **Save states** — <kbd>K</kbd>/<kbd>L</kbd> save/load to localStorage, keyed
  per ROM.
- **Low-latency audio** — AudioWorklet with a ring buffer; underruns (e.g.
  netplay stalls) degrade to silence instead of glitches.
- **Diegetic retro UI** — everything happens "on the TV": boot into static,
  CRT power-on/off animation between views, a 3D cartridge carousel whose
  label art is generated by screenshotting each game's title screen (cached
  in localStorage), NES.css + Press Start 2P chrome, APU-style square-wave
  UI blips, VS MODE room codes presented like a NES password screen, VHS
  wobble + ◀◀ REW overlay while rewinding, and gamepad connect toasts.
- **7 embedded homebrew games** (all freely distributable — see
  `public/roms/manifest.json` and the in-app credits): Streemerz, Super Bat
  Puncher (demo), Lan Master, Chase, Lawn Mower, Blade Buster, Nova the
  Squirrel.
- **Persistent saves** — save states live in localStorage per game; optional
  autosave (every 30 s + on exit/tab close) and a "continue where you left
  off?" prompt when relaunching a game with save data.
- Drag & drop ROM loading, gamepad support (standard mapping).

## Run

```sh
npm install
npm run dev
```

Then drop a `.nes` ROM onto the screen.

### Netplay

1. Player 1 loads a ROM and clicks **Host game** — a 6-letter room code appears.
2. Player 2 opens the app anywhere, types the code, clicks **Join**.
3. The ROM transfers automatically and both games restart in sync.

## Controls

| Key | NES |
| --- | --- |
| Arrows | D-pad |
| X / Z | A / B |
| Enter / Shift | Start / Select |
| K / L | Save / load state |
| Backspace (hold) | Rewind |
| P | Pause |

## Architecture

```
src/
  emulator.ts   jsnes wrapper: ROM loading, pad bitmasks, snapshots
  video.ts      WebGL renderer + CRT shader (power on/off, VHS, static)
  audio.ts      AudioWorklet ring buffer (inline worklet via Blob URL)
  input.ts      keyboard + gamepad → 1-byte pad bitmask
  rewind.ts     snapshot ring buffer
  netplay.ts    peerjs lockstep (input delay, ROM transfer, room codes)
  roms.ts       bundled-library manifest + fetching
  labels.ts     cart label art generated from game screenshots
  sfx.ts        square-wave UI sounds, no assets
  main.ts       view state machine, main loop, carousel, wiring
```

The pad state is a single byte (bit *i* = jsnes button *i*), which is what
makes netplay cheap: the only thing on the wire per frame is that byte.
Determinism of the jsnes core does the rest.

## Built from scratch for this project

- The WebGL CRT pipeline: curvature, scanlines, aperture-grille mask,
  phosphor glow, chromatic aberration, vignette, power-on/off animation, VHS
  rewind wobble, TV static and NO SIGNAL idle screens.
- The deterministic lockstep netplay protocol on top of peerjs data channels
  (input delay, automatic ROM transfer, room codes).
- The rewind system over jsnes serialization.
- The diegetic TV interface: cartridge carousel with labels generated by
  screenshotting each game, ambient room light sampled from the framebuffer,
  save/autosave UX, and the square-wave UI sound synth.

## Known limitations

- *Alter Ego* and *Zooming Secretary* (Shiru) render a black screen in the
  jsnes core and were pulled from the library until the upstream
  incompatibility is understood.
